# 整体架构

## 核心数据流

```
User
  │  编辑 terraform/vsphere/cluster.yaml
  ▼
terraform/vsphere/generate.py        ← Kubernetes Node Generator
  ▼
terraform/vsphere/vm.tf (for_each)   ← 生成/更新
  ▼
Terraform → vSphere VM × N           ← 克隆模板 + guestinfo 注入
  ▼
Cloud-Init (user-data.yaml.tpl)      ← OS 初始化
  ▼
Ubuntu 基础系统 → containerd / kubelet / kubeadm / kubectl / helm / nerdctl
  ▼
kubeadm-ready
  ▼
kubeadm init / join                  ← Kubernetes Cluster (docs/02-Kubernetes)
  ▼
k8s-plugins                          ← 平台扩展
```

## 职责边界（一句话版）

| 层 | 一句话 | 位置 |
|---|---|---|
| Terraform | "创建基础设施" | terraform/vsphere/vm.tf |
| Python | "生成 K8s 节点参数与 VM 定义" | terraform/vsphere/generate.py |
| Cloud-Init | "初始化机器" | terraform/vsphere/user-data.yaml.tpl |
| kubeadm | "创建 Kubernetes" | docs/02-Kubernetes/07-kubeadm实践.md |
| live | "环境组织" | live/ |
| k8s-plugins | "Kubernetes 平台扩展" | k8s-plugins/ |
| OpenWrt | "网络基础设施 (出口/DNS/NAT/代理)" | examples/openwrt |
| Harbor | "Registry 基础设施 (镜像缓存)" | examples/harbor |
| docs | "知识库" | docs/ |

```

  aliyun/     预留 (仅 README)
  aws/        预留 (仅 README)

```

## CN 方案（中国网络环境）

```
Internet → OpenWrt (出口/DNS/NAT/代理) → Harbor (镜像缓存/Proxy Cache) → Kubernetes
```

CN 不是另一套 K8s Terraform，而是网络环境优化方案；三段基础设施相互独立，
K8s Terraform 不硬依赖 OpenWrt/Harbor。详见 docs/13-实战场景/02-CN网络环境.md。
