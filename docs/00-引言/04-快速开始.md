# 快速开始（Windows / Linux / macOS）

## 1. 安装工具

### Windows (PowerShell)
```powershell
winget install Git.Git
winget install HashiCorp.Terraform
winget install Python.Python.3.12
# SSH 客户端 Win10+ 自带; 重开终端后验证:
python --version; terraform version; git --version
```

### Linux (Debian/Ubuntu)
```bash
sudo apt-get install -y git python3 python3-pip wget unzip
wget -O- https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp.gpg
echo "deb [signed-by=/usr/share/keyrings/hashicorp.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list
sudo apt-get update && sudo apt-get install -y terraform
```

### macOS
```bash
brew install git terraform python3
```

## 2. 取仓库 + 依赖 + SSH 密钥

```bash
git clone <你的仓库地址> iac-k8s-esxi
cd iac-k8s-esxi
pip install pyyaml
ssh-keygen -t ed25519        # 若没有密钥; 公钥会被 generate.py 自动探测
```

## 3. 配置

```bash
cd terraform/vsphere
vim cluster.yaml             # 集群名/数量/规格/网段 (字段说明见 docs/99-参考/03-配置参考)
cp ../examples/k8s/terraform.tfvars.example terraform.tfvars
vim terraform.tfvars         # vCenter 地址与账号 (不入 Git)
```

## 4. 生成 + 部署

```bash
python generate.py           # 输出: Cluster/Masters/Workers/节点清单; 生成 vm.tf
terraform init
terraform plan
terraform apply
```

Cloud-Init 首启自动把每台 VM 初始化到 kubeadm-ready（约 3-5 分钟）。
排障: 节点上 `cloud-init status --long` 与 `/var/log/cloud-init-output.log`。

## 5. 引导集群

```bash
ssh <user>@<master-ip>       # kubeadm init ...   (docs/02-Kubernetes/07-kubeadm实践.md)
ssh <user>@<worker-ip>       # kubeadm join ...
```

## 6. 扩展平台

按 `k8s-plugins/README.md` 安装 MetalLB → 存储 → 观测 → GitOps。

## 常见问题

- vCenter 报 datacenter not found / 权限不足 → 核对 terraform.tfvars 与账号权限
- 生成器报"未找到 SSH 公钥" → ssh-keygen 或在 cluster.yaml 指定 ssh.public_key_file
- 更多 → docs/99-参考/05-故障排查.md 与 06-FAQ.md
