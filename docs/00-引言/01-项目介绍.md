# 项目介绍

## 这是什么

**iac-k8s-esxi** 是一个 "Kubernetes Environment Generator + Terraform IaC" 项目：
以 VMware vSphere 为核心平台，用 Terraform + Python + Cloud-Init + kubeadm 从 0 构建
Kubernetes 环境。

它**不是**：大型 Terraform Framework、Python 运维平台、K8s Operator、Shell 脚本集合。

## 解决什么问题

| 手工方式的痛点 | 本项目的解法 |
|---|---|
| 逐台装 VM、点配置、抄 IP | Terraform 按 `vm.tf` 的 for_each 批量创建 |
| 每台 VM 手工装 Docker/K8s 组件 | Cloud-Init 首启自动初始化到 kubeadm-ready |
| IP/主机名/版本靠记忆抄写 | `cluster.yaml` 唯一配置入口，generate.py 生成 vm.tf |
| 换环境要重头来 | 换 cluster.yaml 重新 generate，代码不动 |
| 国内拉不到镜像 | cn 方案: OpenWrt + Harbor (live/lab/vsphere/cn) |
| 做完就忘，无法重复 | 全部声明式，销毁后可重建 |

## 使用场景

- 个人/实验环境的 Kubernetes 集群快速搭建与反复重建
- 小型生产环境的声明式基础设施（配合 live/prod 结构与 docs/11-SRE）
- 中国网络环境下的集群部署（OpenWrt 出口 + Harbor 镜像缓存）
- 学习 Terraform / Cloud-Init / kubeadm 的完整可运行参考实现
