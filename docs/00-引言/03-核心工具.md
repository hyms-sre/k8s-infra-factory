# 核心工具

每个工具按 **是什么 / 解决什么问题 / 一句话理解** 说明。

## Terraform
- **是什么**：HashiCorp 的基础设施即代码工具，HCL 声明式描述基础设施，自动计算变更计划。
- **解决什么**：手工点控制台建 VM 不可重复、易漂移、无法批量。
- **一句话**：写清楚"要什么"，Terraform 负责"怎么做"。详见 docs/01-Terraform/。

## Python
- **是什么**：通用脚本语言；本项目只用标准库 + PyYAML。
- **解决什么**：节点数量 × 规格 × IP × 主机名的组合手写必然出错。
- **一句话**：Kubernetes Node Generator —— cluster.yaml 进、vm.tf 出，仅此而已。

## Cloud-Init
- **是什么**：Linux VM 首启初始化事实标准，读取 #cloud-config YAML 完成配置。
- **解决什么**：VM 装完是"裸"系统，逐台手工初始化不可重复。
- **一句话**：VM 的"开箱自动装机员"。本项目用它把 Ubuntu 初始化到 kubeadm-ready。

## vSphere / vCenter / ESXi
- **是什么**：VMware 虚拟化平台。ESXi 是 hypervisor，vCenter 是集中管理面。
- **一句话**：批量生产 VM 的工厂。当前唯一正式支持的平台。

## Ubuntu Cloud Image
- **是什么**：Ubuntu 官方预构建云镜像（noble 24.04），内置 cloud-init，支持 VMware guestinfo 数据源。
- **一句话**：能被 cloud-init 接管的"半成品"系统盘，作为 Terraform 克隆模板。

## containerd
- **是什么**：Kubernetes 官方支持的容器运行时（CRI 实现）。
- **一句话**：节点上真正干活的容器引擎；Cloud-Init 负责安装配置。

## kubeadm / kubelet / kubectl
- **是什么**：K8s 官方三件套。kubeadm 建集群；kubelet 是节点代理；kubectl 客户端。
- **一句话**：kubeadm 盖楼、kubelet 看楼、kubectl 遥控。Cloud-Init 只装到 kubeadm-ready，集群引导见 docs/02-Kubernetes/07。

## Kubernetes
- **是什么**：容器编排平台：调度、自愈、服务发现、滚动升级。
- **一句话**：数据中心级的"容器操作系统"。

## Helm
- **是什么**：Kubernetes 包管理器（chart 模板化安装）。
- **一句话**：K8s 世界的 apt/brew。Cloud-Init 预装，插件大量使用。

## Harbor
- **是什么**：开源企业级镜像仓库，支持 Proxy Cache。
- **一句话**：局域网内的"镜像中转站 + 缓存"。cn 方案核心。详见 docs/13-实战场景/02。

## OpenWrt
- **是什么**：开源路由器操作系统，x86 版可跑在 VM。
- **一句话**：装在 VM 里的"集群网关路由器"（DNS/NAT/代理出口）。
