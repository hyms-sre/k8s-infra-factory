# 镜像与供应链

## 威胁面

应用 = 基础镜像 + 依赖 + 构建链 + 传输渠道——每一环都可能被投毒
（恶意基础镜像、依赖投毒、registry 中间人、CI 凭据泄漏）。

## 镜像安全实践

1. **来源可信**：官方/自建镜像；基础镜像用 digest 固定 `@sha256:...`
2. **最小镜像**：distroless/alpine/slim；多阶段构建；不装调试工具进生产镜像
3. **非 root 运行**：`USER 1000` + Pod Security
4. **不进镜像的东西**：密钥、.git、构建缓存

## 漏洞扫描：Trivy

```bash
trivy image harbor.example.local/app:1.0          # 镜像
trivy fs .                                        # 代码目录/依赖
trivy k8s --report summary cluster                # 集群内全量
```

集群内持续扫描：trivy-operator（k8s-plugins/security/trivy）——扫描结果以
CR（VulnerabilityReport）呈现，可接告警/准入。

## SBOM 与签名

- **SBOM**（软件物料清单）：`syft <image>` 输出 SPDX/CycloneDX → 依赖可追溯
  （新漏洞爆发时快速定位"我受影响吗"）
- **签名与验签**：cosign 签名镜像；Kyverno 校验"只有已签名镜像可部署"
  （供应链闭环，见 05-策略引擎）

## CI 里的位置

构建后自动：trivy 扫描（高危阻断）→ syft 生成 SBOM（附件归档）→ cosign 签名 → push。
