# 完整流水线与选型

## Argo Workflows

Argo 系的批处理/流水线引擎（Workflow CRD），DAG 编排、artifact 传递（S3/MinIO）。
更适合：数据流水线、定时批处理、ML pipeline。CI 场景与 Tekton 二选一。

## 推荐：CI/CD 解耦架构（本项目标准形态）

```
开发者 → Git (应用仓库)
            │ CI: build/test/镜像/push Harbor (Jenkins/GitLabCI/Tekton 均可)
            ▼
        Git (GitOps 仓库: manifests/helm values)   ← CI 只改这里的镜像 tag
            │ CD: ArgoCD 同步到集群 (docs/05-GitOps)
            ▼
        Kubernetes
```

价值：**Git 是部署状态的唯一真值**；发布=一次 commit；回滚=git revert；
CI 与 CD 权限分离（CI 不需要生产集群凭据）。

## 端到端示例（本项目环境）

1. push 代码 → CI 构建镜像 `harbor.example.local/app:<sha>`
2. CI 用 PR 修改 GitOps 仓库 `deploy/dev/kustomization.yaml` 的 image
3. ArgoCD 检测漂移 → 同步到集群 → 健康检查（Rollout 可加金丝雀，见 docs/05-GitOps/03）
4. 发版 = PR merge 到 prod 目录

## 选型速查

| 场景 | 选择 |
|---|---|
| 存量 Jenkins / 复杂异构 | Jenkins (K8s agent) |
| 自托管 GitLab | GitLab CI + K8s Runner |
| 全云原生新集群 | Tekton 或 Argo Workflows |
| 部署一律 | GitOps (ArgoCD/Flux) |
