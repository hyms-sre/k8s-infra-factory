# 14-体系学习

把散落在各分类里的知识，组织成**一条可执行的学习路径**。

前面 13 个分类是"按主题平铺"的知识库 —— 适合查阅，不适合入门。
本模块是"按阶段推进"的学习地图：**每个阶段都有前置条件、学习目标、动手实验和检查点**，
跟着走完，就能从零掌握 iac-k8s-esxi 这套栈，并能独立搭出、改坏、再重建一个集群。

## 本模块与其它分类的关系

| | 其它分类（00–13） | 本模块（14） |
|---|---|---|
| 组织方式 | 按**主题**平铺 | 按**阶段**递进 |
| 适合 | 查阅、深入某个专题 | 系统入门、按序推进 |
| 产出 | 知识点 | 可运行的环境 + 自测通过 |

本模块**不重复**讲知识点，而是告诉你**在什么阶段、为了什么目的、去读哪一篇**。

## 怎么用这个模块

1. **先看 [学习地图](01-学习地图.md)** —— 了解阶段之间的依赖关系，确认自己该从哪一阶段进入。
2. **按阶段推进** —— 每篇文档的结构是固定的：前置条件 → 学习目标 → 核心概念 → 仓库文件 → 动手实验 → 检查点 → 常见坑。
3. **检查点必须过** —— 每个阶段的检查点过不了，不要进入下一阶段，否则后面会越学越乱。
4. **最后做 [自测清单](08-自测清单与验收.md)** —— 逐项打勾，确认自己真的掌握了。

## 前置要求

开始阶段 1 之前，请确认：

- 会用 Linux 命令行（`ssh`、文件编辑、`systemctl` 基础）
- 有一台能访问 **vSphere/vCenter** 的机器（或愿意先用 `terraform plan` 只读体验）
- 准备一个 **Ubuntu 24.04 Cloud Image** 模板（见 [12-云平台](../12-云平台/index.md)）
- Python ≥ 3.9、Terraform ≥ 1.5

> 只想先感受一下？直接跳到 [00-引言/04-快速开始](../00-引言/04-快速开始.md)，
> 跑通 `deploy → destroy` 一轮再回来按阶段学。
