# 场景: 小型生产 / 离线环境 / 灾备环境

## 小型生产 Kubernetes（3-6 节点）

拓扑建议：

```
3 × master (3C/6G/100G, taint 隔离)   # etcd 奇数, --control-plane-endpoint=<VIP>
3 × worker (8-16C/16-32G + 数据盘)     # 业务负载
基础设施: Harbor/OpenWrt 独立 VM (不占 K8s 节点)
```

清单（在 lab 全流程跑通后再做）：

1. HA 控制面：keepalived/haproxy 或外部 LB 提供 API VIP
2. 存储：Longhorn 副本 ≥2 + 备份到 MinIO；关键库走 docs/08-数据库 HA 模式
3. 安全：RBAC 收敛、Kyverno 基线、admin.conf 轮换纪律
4. 观测：监控栈 + SLO（docs/11-SRE）
5. 变更管理：GitOps + prod 手动 sync；terraform 变更走 PR + plan 截图
6. 运维预案：节点故障（drain/uncordon）、证书续期、etcd 备份恢复演练

## 离线环境（无外网）

1. **物料预取**（有网侧）：apt 离线包/镜像 tar/k8s 二进制 → `scripts/<平台>/prefetch-files`
2. **私有源**：Harbor 兼任 apt/npm/pypi 代理（或 Nexus）；kubeadm 镜像 push 到 Harbor
3. **cluster.yaml 调整**：apt_mirror/工具 url 指向内网 HTTP；harbor.upstreams 关闭
   （无上游可缓存）
4. **节点初始化验证**：cloud-init 全程不触外网（模板中 apt源/下载地址全部内网化）
5. 交付物：离线包清单 + 版本矩阵（docs/99-参考/04-版本矩阵）

## 灾备环境

- **热备（同构集群待命）**：live/prod 之外的第二个环境常备，Longhorn backup / velero
  定期恢复到备集群验证
- **冷备（重建能力）**：本仓库即"灾备预案"——cluster.yaml + live/ 配置 + 备份目标
  可在任意 vSphere 从零重建（RTO = 部署时长 + 数据恢复）
- **演练季度化**：从备份恢复一次核心应用到隔离 namespace，记录 RTO/RPO 实测
  （docs/07-存储/05、docs/11-SRE/03）
