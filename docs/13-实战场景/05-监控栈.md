# 场景: Prometheus + Grafana + Loki（监控栈）

## 目标

集群与业务可观测：指标 + 日志 + 告警，一套面板。

## 部署

### 1. kube-prometheus-stack（指标+告警+面板）

```bash
helm install prom prometheus-community/kube-prometheus-stack -n monitoring --create-namespace
# 内含: Prometheus Operator/CRD, node-exporter(DS), kube-state-metrics, Alertmanager, Grafana
```

### 2. Loki + Promtail（日志）

```bash
helm install loki grafana/loki -n monitoring --set singleBinary.replicas=1
helm install promtail grafana/promtail -n monitoring    # DaemonSet 采集容器日志
```

### 3. 暴露 UI

Grafana Service → LoadBalancer（MetalLB 池固定 IP）或 Gateway API HTTPRoute。

## 接入业务

```yaml
kind: ServiceMonitor        # Prometheus Operator CR: 自动发现抓取目标
spec:
  selector: {matchLabels: {app: api}}
  endpoints: [{port: http-metrics}]
```

日志查询：Grafana Explore → Loki（`{namespace="prod", app="api"} |= "ERROR"`）。

## 告警最小集

| 告警 | 表达式要点 |
|---|---|
| 节点失联 | up{job="node"} == 0 for 5m |
| Pod 重启风暴 | increase(kube_pod_container_status_restarts_total[1h]) > 5 |
| PVC 快满 | kubelet_volume_stats_available_bytes / capacity < 10% |
| 证书过期 | cert-manager 证书 remaining < 14d |
| 核心 SLO | 错误率 burn rate（docs/11-SRE/01） |

Alertmanager 路由到企业 webhook；通知模板带 Runbook 链接。

## 容量与保留

- Prometheus 本地保留 15d；长期 → VictoriaMetrics（docs/04-可观测性/05）
- Loki 保留 30d + compactor；监控栈自身资源 requests 合理设置，防 OOM 连坐

## cn 环境注意

quay/ghcr 镜像预拉取或走 Harbor proxy（docs/13-实战场景/02），Grafana 插件/面板源同理。
