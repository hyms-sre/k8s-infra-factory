# 术语表

| 术语 | 含义 |
|---|---|
| IaC | Infrastructure as Code，用代码声明基础设施 |
| HCL | HashiCorp 配置语言（.tf 文件） |
| Provider | Terraform 与平台 API 的适配器（vmware/vsphere） |
| Resource / Data Source | 要创建的对象 / 只读查询已存在的信息 |
| State (tfstate) | Terraform 的资源账本（真实资源 ↔ 配置映射） |
| for_each | 按稳定键批量创建资源实例（本项目 vm.tf 核心） |
| templatefile() | Terraform 模板渲染函数（${}/%{if}/%{for}） |
| Cloud-Init | Linux VM 首启初始化标准（#cloud-config） |
| guestinfo | VMware VM 的额外配置通道，cloud-init 从中读取 user-data/metadata |
| user-data / meta-data | cloud-config 初始化数据 / 实例与网络元数据 |
| kubeadm | K8s 官方集群引导工具（init/join/upgrade） |
| kubelet | 每节点代理，管理 Pod 生命周期 |
| containerd | 容器运行时（CRI 实现） |
| CRI / CNI / CSI | 容器运行时/网络/存储 的 K8s 标准接口 |
| pause 镜像 (sandbox) | Pod 基础设施容器，版本须与 kubeadm 匹配 |
| pod_cidr / service_cidr | Pod IP 池 / Service 虚 IP 池 |
| Control Plane | 控制面：apiserver/etcd/scheduler/controller-manager |
| CNI 插件 | Pod 网络（Cilium/Calico/Flannel） |
| Service / Ingress / Gateway API | 服务暴露三层抽象 |
| MetalLB | 裸金属 K8s 的 LoadBalancer 实现（L2/ARP） |
| PV / PVC / StorageClass | 存储卷 / 申请 / 动态供给模板 |
| Longhorn | 分布式块存储（聚合节点数据盘） |
| Harbor | 企业镜像仓库 + Proxy Cache |
| Proxy Cache | Harbor 拉上游镜像并缓存的代理项目 |
| OpenWrt | 开源路由器 OS（本项目做网关/DNS/代理出口） |
| OpenClash | OpenWrt 上的代理分流工具 |
| GitOps | Git 作为部署状态真值，agent 持续调和 |
| ArgoCD / Flux | GitOps 持续部署工具 |
| Operator | CRD + 控制器，把运维知识编码 |
| RBAC / SA | 基于角色的访问控制 / ServiceAccount |
| SLI / SLO / Error Budget | 可靠性指标 / 目标 / 容错额度 |
| RTO / RPO | 恢复耗时目标 / 数据丢失容忍 |
| IDP | 内部开发者平台 |
