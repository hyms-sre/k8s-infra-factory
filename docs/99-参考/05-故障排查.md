# 故障排查

## Terraform / vSphere

| 现象 | 原因与处理 |
|---|---|
| `datacenter 'X' not found` | terraform.tfvars 数据中心名不对 |
| `template 'X' not found` | 模板名/数据中心不符 |
| `error fetching network` | 端口组名不符（大小写/空格） |
| 克隆卡住 | datastore 空间不足 / 并发克隆锁；看 vCenter 任务 |
| 改节点名触发销毁重建 | network.date 改动导致显示名变化；main.tf 已 ignore_changes=[name] 兜底，已部署集群固定 date |
| 旧 state 地址对不上 | `terraform state mv 'vsphere_virtual_machine.vm["旧键"]' 'vsphere_virtual_machine.k8s_node["新键"]'`（键=主机名） |
| nodes/cluster 报属性缺失 | vm.tf 是生成物——重新 `python generate.py`，勿手工编辑 |

## Cloud-Init / 节点初始化

| 现象 | 原因与处理 |
|---|---|
| 首启拿不到 IP | guestinfo 未注入或网卡名不符 → 核对 network.interface |
| cloud-init 失败 | `cat /var/log/cloud-init-output.log` 定位；修复后重建 VM（per-instance 语义不会自动重跑） |
| apt 签名/404 | apt_mirror 与 apt_suite 不匹配（24.04=noble） |
| kubelet 起不来 | swap/SystemdCgroup/cgroup 驱动 → `journalctl -u kubelet` |

### ⚠️ containerd config_path 必须单一路径

containerd 2.x CRI 无法解析 `"a:b"` 多路径，**静默忽略整个 certs.d**——
crictl 直连超时而 nerdctl 正常，极易误判。检查：

```bash
grep config_path /etc/containerd/config.toml   # 必须是单一路径值
```

## Kubernetes

| 现象 | 处理 |
|---|---|
| join token 失效 | master 重新 `kubeadm token create --print-join-command` |
| 节点 NotReady | CNI 未装/未就绪: `kubectl -n kube-system get pods` |
| init 卡 preflight | swap/containerd/内核参数 → 查 cloud-init 是否 done |
| 拉镜像超时 (cn) | 预拉取+tag 或 Harbor → docs/13-实战场景/02 |
| kubectl 证书与 IP 不符 | 用 advertise-address/VIP 访问，或重建控制面证书 |

## Harbor

| 现象 | 处理 |
|---|---|
| prepare 报 `KeyError: 'max_job_workers'` | harbor.yml 必须基于 harbor.yml.tmpl 生成 |
| 改配置不生效 | 必须 `./prepare` + `docker compose up -d` |
| core 重启: postgres 认证失败 | `docker exec -u postgres harbor-db psql -U postgres -c "ALTER USER postgres WITH PASSWORD '<yml 口令>';"` |
| 节点拉取 404→超时 | certs.d 项目名与 Harbor proxy 项目不一致 |
| 证书不受信 | 节点装 CA + update-ca-certificates + 重启 containerd |

## OpenWrt / MetalLB / Envoy Gateway

| 现象 | 处理 |
|---|---|
| uci add_list 越加越多 | 先 del_list 再 add_list |
| OpenClash 装不上 | 需 dnsmasq-full（先 remove dnsmasq）+ kmod-tun/ip-full |
| VM 名含 `[]` 操作失败 | govc 转义 `\[222.210\]` |
| MetalLB CRD 建完 not found | 清 ~/.kube/cache；L2Advertisement 用 v1beta1 |
| EG CRD 注解超限 | `kubectl apply --server-side --force-conflicts` |
| 解析不到本地域 | uci address + dnsmasq restart + 节点 DNS 指向 OpenWrt |

## 其他

| 现象 | 处理 |
|---|---|
| pip pyyaml 失败 (PEP668) | `pip install --user pyyaml` 或 venv |
| 生成器报未找到 SSH 公钥 | ssh-keygen 或 cluster.yaml 指定 ssh.public_key_file |
| Windows 脚本换行符报错 | git config core.autocrlf input |
