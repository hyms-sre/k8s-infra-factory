# 文件说明

## 源码与配置（入 Git）

| 文件 | 生成者 | 生成时机 | 用途 | 备份 |
|---|---|---|---|---|
| `terraform/vsphere/cluster.yaml` | 用户 | 初次+变更 | 集群定义唯一入口 | 随 Git |
| `terraform/vsphere/generate.py` | 人维护 | — | 节点参数生成器 | 随 Git |
| `terraform/vsphere/vm.tf` | **generate.py** | 每次 generate | 节点数据+for_each 资源 | 随 Git（可再生成） |
| `terraform/vsphere/{provider,versions,variables,data,locals,main,outputs}.tf` | 人维护 | — | 平台层 | 随 Git |
| `terraform/vsphere/{user-data,meta-data}.yaml.tpl` | 人维护 | — | Cloud-Init 模板 | 随 Git |
| `terraform/vsphere/.terraform.lock.hcl` | terraform init | init | provider 版本锁定 | 随 Git |
| `live/**`、`k8s-plugins/**`、`examples/**` | 人维护 | — | 环境/插件/示例 | 随 Git |

## 生成物（不入 Git，可再生）

| 文件 | 生成者 | 用途 | 备份 |
|---|---|---|---|
| `.terraform/` | terraform init | provider 插件缓存 | 否 |
| `downloads/` | prefetch 脚本 | 安装包缓存 | 否 |

## 凭据与状态（不入 Git，**必须备份**）

| 文件 | 生成者 | 生成时机 | 用途 | 备份 |
|---|---|---|---|---|
| `terraform/vsphere/terraform.tfvars` | 用户 | 部署前 | vCenter 凭据 | ✅ 密码管理器 |
| `terraform/vsphere/terraform.tfstate`(+backup) | terraform | apply 后 | 基础设施账本 | ✅ 每次变更 |
| `~/.ssh/id_ed25519` | ssh-keygen | 一次性 | SSH 私钥 | ✅ |
| `~/.kube/config` | 用户复制 | kubeadm init 后 | 集群访问 | ✅ |
| `secrets/secrets.env` | 用户登记 | 部署后 | 口令登记簿 | ✅ |
| `AGENT.md` | 人/Agent | — | 本地维护约定（gitignore） | 可选 |

### terraform.tfstate 专项

- **是 Terraform 的账本**（资源 ID/属性映射）；删了 = 不再认识现有 VM，apply 会重建
- 位置：与 main.tf 同目录；重构目录时**跟随移动**，地址变化用 `terraform state mv`
- 含敏感明文 → 保密级别同密码；建议定期复制备份或启用远端 backend
（backend 选项见 docs/01-Terraform/06-State与Backend.md）
