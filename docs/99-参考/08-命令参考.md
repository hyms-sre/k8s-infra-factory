# 命令参考

## 生成与部署（terraform/vsphere/ 内）

```bash
python generate.py                          # cluster.yaml → vm.tf（含节点摘要）
python generate.py --config other.yaml      # 指定配置
terraform init                              # 首次/换 provider
terraform plan                              # 预览（+创建 -销毁 ~更新）
terraform apply                             # 应用
terraform destroy                           # 销毁全部节点 VM（危险）
terraform fmt -recursive && terraform validate
```

## State

```bash
terraform state list
terraform state mv 'vsphere_virtual_machine.k8s_node["旧键"]' '...["新键"]'
terraform import 'vsphere_virtual_machine.k8s_node["x"]' vm-1234
```

## 节点检查

```bash
ssh <user>@<node-ip>
cloud-init status --long
cat /var/log/cloud-init-output.log
systemctl status containerd kubelet
crictl ps / crictl images
grep config_path /etc/containerd/config.toml   # 必须单一路径
```

## 集群引导与日常

```bash
kubeadm init --image-repository=... --pod-network-cidr=... --apiserver-advertise-address=...
kubeadm token create --print-join-command
kubeadm certs check-expiration / renew all
mkdir -p ~/.kube && sudo cp /etc/kubernetes/admin.conf ~/.kube/config

kubectl get nodes -o wide
kubectl -n kube-system get pods
kubectl describe pod <p> / logs [-p] <p> / exec -it <p> -- sh
kubectl taint node <n> key-            # 去污点
kubectl drain <n> --ignore-daemonsets  # 维护前
kubectl uncordon <n>
kubeadm config images list --kubernetes-version=v1.36.4   # 校验镜像
```

## 插件速查

```bash
kubectl apply -f k8s-plugins/networking/metallb/metallb-native.yaml
kubectl apply -f k8s-plugins/storage/longhorn/longhorn.yaml
kubectl patch storageclass longhorn -p '{"metadata":{"annotations":{"storageclass.kubernetes.io/is-default-class":"true"}}}'
kubectl -n metallb-system get IPAddressPool,L2Advertisement
helm list -A
```

## 排障三板斧

```bash
journalctl -u containerd --since "10 min ago" | grep -E "host=|failed"
kubectl get events -A --sort-by=.lastTimestamp | tail -30
curl -s https://harbor.example.local/v2/ -o /dev/null -w '%{http_code}\n'
```
