# 凭据说明

## 全景表

| 凭证 | 用途 | 在哪里配置 | 在哪里保存 | 何时生成 | 如何修改 | 入 Git |
|---|---|---|---|---|---|---|
| SSH 私钥 | 登录节点/Harbor/OpenWrt | 不需配置，自动使用 | `~/.ssh/id_ed25519`（Win: `C:\Users\<你>\.ssh\`） | `ssh-keygen -t ed25519` | 重新生成后更新公钥 | **禁止** |
| SSH 公钥 | 注入 VM authorized_keys | cluster.yaml `ssh.public_key_file`（空=自动探测） | `~/.ssh/id_ed25519.pub` | 随私钥 | 换公钥重新 generate/apply | 允许 |
| VM 用户密码（可选） | 备用登录 | cluster.yaml `ssh.vm_password` | 同左（生成进 vm.tf） | 部署时 | 改配置重建 VM | **禁止** |
| Linux 运维用户 | VM 日常操作 | cluster.yaml `os.user` | — | 部署时 | 改配置重建 | 允许(用户名) |
| vSphere 用户/密码 | vCenter API | `terraform/vsphere/terraform.tfvars` 或 `TF_VAR_vsphere_user/password` | tfvars（gitignore）/环境变量 | 管理员创建 | 改 tfvars | **禁止** |
| Kubernetes admin (admin.conf) | 集群管理员 | — | master `/etc/kubernetes/admin.conf` → `~/.kube/config` | kubeadm init | `kubeadm certs renew` / 重建 | **禁止** |
| Kubeconfig | kubectl 访问 | KUBECONFIG env 可选 | `~/.kube/config` | 复制 admin.conf | 重新拷贝 | **禁止** |
| Join token | worker 加入 | — | 24h 有效 | `kubeadm token create` | 过期重建 | — |
| Harbor admin | 镜像仓库管理 | 安装时设置 | Harbor VM harbor.yml；登记 `secrets/secrets.env` | 部署时 | Harbor UI | **禁止** |
| Harbor DB 密码 | 内置 PostgreSQL | harbor.yml `database.password` | 同上 | 首次安装 | 必须与 DB 实际一致（否则 core 起不来） | **禁止** |
| OpenWrt root | 网关管理 | 部署时 chpasswd | 登记 `secrets/secrets.env` | 部署时 | SSH 内 chpasswd | **禁止** |

## 铁律

1. 私钥/密码/token **禁止入库**；禁止硬编码在任何源码、模板、文档示例中
2. `*.tfvars`（example 除外）、`*.tfstate`、`.env`、`*.key`、`secrets/secrets.env`、
   `AGENT.md` 已全部 gitignore
3. 真实口令只存两处：密码管理器 + `secrets/secrets.env`（本地登记簿，模板见
   `secrets/secrets.env.example`，全部占位符）
4. admin.conf 等同集群 root，按最高敏感级对待；泄露处理：轮换证书或重建集群
5. 凭据轮换周期建议：vCenter/数据库类密码半年；join token 天然 24h 过期；SSH 密钥一年评估

## SSH 密钥路径速查

```
Windows : C:\Users\<用户名>\.ssh\id_ed25519(.pub)
Linux   : ~/.ssh/id_ed25519(.pub)
macOS   : ~/.ssh/id_ed25519(.pub)
其他    : known_hosts (主机指纹, 自动维护)
```
