# 配置参考

配置只有两个入口：`terraform/vsphere/cluster.yaml`（集群定义，入 Git）与
`terraform/vsphere/terraform.tfvars`（凭据，不入 Git）。逐字段注释样例：
`examples/k8s/config.example.yaml`。

## cluster.yaml 关键字段

| 字段 | 说明 | 默认/示例 |
|---|---|---|
| `cluster.name/environment/location/id` | 命名来源: 主机名 `<env>-<loc>-<id>-<role>-<NN>`；显示名 `<id>-<role><NN>[<IP后两段>]-<date>` | lab / hq / k8s01 |
| `masters.count|cpu|memory|disk|data_disk|ips` | master 节点定义（count 建议奇数） | 3 / 4 / 6144 / 100 / 50 / [] |
| `workers.*` | worker 节点定义（同构） | 3 / 16 / 16384 / 200 / 50 |
| `network.interface` | VM 网卡名（vmxnet3 → ens192） | ens192 |
| `network.cidr|gateway|dns|ip_start` | 网段/网关/DNS/分配起点 | 172.16.222.0/24 等 |
| `network.date` | 显示名日期段；**已部署集群固定**，改动=改名（VM 重建） | auto |
| `kubernetes.version` | 1.33-1.37（联动目录见 generate.py K8S_CATALOG） | 1.36 |
| `kubernetes.apt_repo` | K8s apt 源（`{version}` 占位） | pkgs.k8s.io（cn 换 aliyun） |
| `kubernetes.pause_registry` | pause 镜像 registry | registry.k8s.io（cn 换 aliyun） |
| `kubernetes.pod_cidr|service_cidr` | 集群网段（须与 init 参数一致） | 10.244.0.0/16 / 10.96.0.0/12 |
| `os.user|group|timezone|apt_mirror|apt_suite|ntp` | 系统基线 | appuser / noble / Asia/Shanghai |
| `ssh.public_key_file|enable_password_auth|vm_password` | 登录方式（默认仅密钥） | "" / false / "" |
| `tools.helm|nerdctl|bash_completion` | 工具开关与下载 URL | 见样例（cn 换镜像源） |
| `harbor.enabled|host|ip|upstreams` | 镜像代理（cn 启用；**项目名须与 Harbor 一致**） | false |

## terraform.tfvars（凭据模板见 examples/k8s/terraform.tfvars.example）

| 变量 | 说明 |
|---|---|
| `vsphere_user / vsphere_password` | vCenter 账号（sensitive） |
| `vsphere_server / vsphere_datacenter` | vCenter 地址 / 数据中心 |
| `vsphere_host / vsphere_datastore / vsphere_network` | 独立 ESXi 主机 / 数据存储 / 端口组 |
| `vm_template_name` | Ubuntu Cloud Image 模板名 |

环境变体：default → `live/lab/vsphere/default/`；cn → `live/lab/vsphere/cn/cluster/cluster.yaml.example`。
值传递优先级：`-var` > 环境变量 `TF_VAR_*` > terraform.tfvars > variable default。
