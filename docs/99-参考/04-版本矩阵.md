# 版本矩阵

## K8s 版本联动目录（真值源: terraform/vsphere/generate.py 的 K8S_CATALOG）

| K8s 版本 | pause 镜像版本 | crictl 版本 | 说明 |
|---|---|---|---|
| 1.33 | 3.10 | v1.33.0 | 保守线，生态最成熟 |
| 1.34 | 3.10 | v1.34.0 | 过渡线 |
| 1.35 | 3.10 | v1.35.0 | 建议 Cilium ≥ 1.17 |
| 1.36 | 3.10.1 | v1.33.0 | ★ 实测生产版本 |
| 1.37 | 3.11 | v1.34.0 | 最新 GA，逐项验证 CNI/CSI 兼容 |

pause 的 registry 前缀由 cluster.yaml 的 `kubernetes.pause_registry` 提供
（default: registry.k8s.io；cn: registry.aliyuncs.com/google_containers）。
校验命令：`kubeadm config images list --kubernetes-version=<full>`。

生产环境变更前先在 live/lab 复刻验证。
