# 备份与恢复

## 备什么（按丢失代价排序）

| 对象 | 工具 | 频率 |
|---|---|---|
| etcd（整个集群定义） | etcdctl snapshot | 每日 |
| PV 数据 | Longhorn backup / velero | 每日 |
| 集群外状态 | terraform.tfstate、cluster.yaml、凭据 | 每次变更 |
| 应用级导出 | pg_dump / es snapshot | 业务定 |

## Velero（集群级备份恢复）

```bash
velero install --provider aws --bucket velero \
  --backup-location-config s3Url=http://minio:9000,s3ForcePathStyle=true

velero backup create daily-$(date +%F) --include-namespaces prod
velero restore create --from-backup daily-xxxx            # 整体恢复
velero backup create --include-resources pvc,pod -l app=db  # 选择性
```

Velero 走 CSI 快照接口 → 与 Longhorn 协作（快照+数据上传）。

## etcd 快照（最关键）

```bash
ETCDCTL_API=3 etcdctl snapshot save /backup/etcd-$(date +%F).db \
  --endpoints=https://127.0.0.1:2379 --cacert=/etc/kubernetes/pki/etcd/ca.crt \
  --cert=/etc/kubernetes/pki/etcd/server.crt --key=/etc/kubernetes/pki/etcd/server.key
```

恢复：`etcdctl snapshot restore`（生成新 data-dir）→ 替换 etcd 数据目录 →
静态 Pod 自动重启；多 master 需全部按同一快照恢复。

## 恢复演练（没有演练的备份等于没有备份）

每季度：在 live/lab 复刻环境 → 恢复 etcd + Longhorn backup → 验证应用可用。
记录 RTO（多久恢复）/ RPO（丢多少数据）实测值，作为 SLO 输入（docs/11-SRE）。
