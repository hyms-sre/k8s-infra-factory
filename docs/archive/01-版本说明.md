# 01 — 软件版本说明

> 选型原则：K8s 取阿里云 `kubernetes-new/core/stable` 中最新且生态成熟的 **v1.36**（v1.37.0 刚 GA 生态未稳；如需切换只需改 apt 源路径的 `v1.36`）。
> 其余组件均为 2026-09 时点各自最新的稳定大版本，且全部验证过在本环境可离线部署。

## 国内镜像源实测结论（cn profile 依据，2026-09-07）

| 源 | 结论 |
|---|---|
| `mirrors.aliyun.com/kubernetes-new` | ✅ apt 源 |
| `registry.aliyuncs.com/google_containers` | ✅ kubeadm 全套镜像 + pause |
| `docker.1ms.run` | ✅ docker.io 全引用拉取（certs.d mirror 方式不兼容，必须全引用+tag） |
| `quay.m.daocloud.io` / `ghcr.m.daocloud.io` | ⚠️ 可用但限流（403 时重试或换 Harbor proxy / crane） |
| `ghcr.nju.edu.cn` | ❌ 本环境不通 |
| registry.k8s.io / docker.io / downloads.openwrt.org | ❌ 被墙，禁止直连 |

> `make deploy PROFILE=direct` 时全部切回官方上游源（profiles/direct.yml）。
