## 4. 不一致 / 风险清单（按优先级）

### P0 — 阻塞最终收口

- **R0：OpenClash 订阅缺失**。`secrets/secrets.env` 的 `VAULT_OPENCLASH_SUBSCRIPTION` 为空。填入 → OpenWrt 启动 OpenClash → `make resume` → 自动补齐 `dockerhub`/`gcr` → 复跑 `make verify` 应达 **28/28**。
  （注：`k8s` 上游是 `registry.k8s.io` 307 跳转 `asia-east1-docker.pkg.dev`，需确认 OpenClash 规则能覆盖该域名，否则该项仍可能失败。）

### P1 — 会破坏"重跑/重建"的可复现性

- **R1：Headlamp 版本漂移**。`scripts/47-headlamp.sh:13,37` 使用 `headlamp:v0.30.1`，而实际部署与文档均为 **v0.45.0**。重跑该脚本会部署错版本。
- **R2：MetalLB 地址池漂移**。`scripts/00-env.sh:50` `METALLB_POOL="172.16.222.211-172.16.222.220"`，含 .211；实际已拆为 `lab-pool` .212-.220 + `headlamp-pool` .211/32（TIMELINE 记录该修复是手工做的）。重跑 `44-metallb.sh` 会重建重叠池。
- **R3：OpenWrt IP 漂移**。`examples/kubernetes/terraform.tfvars:7,64` 与 `scripts/govc-openwrt.sh:44` 仍写 **.208**，实际为 **.210**（docs/00、README、00-env 均为 .210）。
- **R4：Harbor 配置写法与文档矛盾**。`docs/04` 明确"手写精简 harbor.yml 会因缺 `max_job_workers` 等字段启动失败，必须基于 `harbor.yml.tmpl` 打补丁"，但 `scripts/30-harbor-init.sh:37` 恰恰是手写精简版。二者必有一处需修正。
- **R5：GatewayClass 未脚本化**。`scripts/45-envoy-gateway.sh` 只 `get gatewayclass eg`，未 `apply`；而 docs/05 与 TIMELINE 均记录该对象需手工创建。全新环境重跑会卡在 Gateway 无法 Programmed。
- **R6：Headlamp 取像未脚本化**。文档说明 ghcr 被阻断、靠 Windows 侧 `crane` 拉取后分发，但 `47-headlamp.sh` 里只有 `ghcr.m.daocloud.io` 中转路径（该路径文档记载不可用）。重建时该步会失败。
- **R7：Profile 未接线**。`profiles/cn.yml`、`direct.yml` 无消费者；`00-env.sh:11` 的 `PROFILE` 只出现在 echo 里。README 宣称的"双 Profile 切换"当前无代码支撑。
- **R8：Profile 内容本身也过期**。`cn.yml:19` / `direct.yml:16` 的 `endpoint: harbor.test.local` ≠ 实际 `harbor.yjscloud.local`；`cn.yml:26` 的 `vip: 172.16.222.210` 实为 OpenWrt IP，单 master 拓扑并无 VIP。

## 5. 建议的收尾顺序

**第 1 步（解锁 28/28）**：填 `VAULT_OPENCLASH_SUBSCRIPTION` → OpenWrt LuCI 启动 OpenClash → 在 Harbor VM 上 `curl -sI https://registry-1.docker.io/v2/` 返回 401/200 → `make resume PROFILE=cn` → `make verify`，确认 `dockerhub`/`gcr` 项目补齐并刷新 `docs/07`。

**第 2 步（修复可复现性，R1–R8）**：优先修 4 处会直接导致重建失败的：Headlamp 版本、MetalLB 池、GatewayClass、OpenWrt IP；随后决定 Profile 是"接线"还是"降级为文档说明"。

**第 3 步（仓库治理，R9–R15）**：`git init`；先把 `*.tfvars`、`proxypull*`、`.zcode/` 加进 `.gitignore`，再轮换已泄露的 vCenter/Harbor DB 口令；归档或删除遗留脚本与 `examples/ubuntu/`。
