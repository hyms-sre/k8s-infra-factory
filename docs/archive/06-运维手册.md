## 2. 断点续跑（Manual Action Required 流程）

```bash
# 任一脚本遇到无法自动处理的阻塞 (如 OpenClash 订阅缺失) 会:
#   1) 打印 MANUAL ACTION REQUIRED + 阻塞原因 + 处理步骤
#   2) 写入 master-01:/opt/iac/state/BLOCKED
#   3) 退出码 42 (不无限重试)
# 人工处理后:
make resume PROFILE=cn        # 已完成 phase (state/<phase>.done) 自动跳过
```

## 4. 扩容（加 worker）

1. tfvars 增加 VM 条目（IP 从 .205/.206 取，命名照规范）
2. `terraform apply -var-file=examples/kubernetes/terraform.tfvars`
3. `make resume`（40/41 自动覆盖新节点）
4. 新节点取 join 命令：master-01 `kubeadm token create --print-join-command`

## 5. 备份

```bash
# etcd 快照 (master-01, 建议 cron 每日)
sudo kubeadm certs check-expiration    # 证书有效期
sudo nerdctl -n k8s.io run --rm --net=host -v /etc/kubernetes/pki/etcd:/pki:ro \
  -v /backup:/backup registry.aliyuncs.com/google_containers/etcd:3.6.8-0 \
  etcdctl snapshot save /backup/etcd-$(date +%F).db \
  --endpoints=127.0.0.1:2379 --cacert=/pki/ca.crt --cert=/pki/server.crt --key=/pki/server.key
```

## 7. 已知事项 / 可选扩展

- **Harbor Proxy Cache 待激活**：OpenWrt OpenClash 填订阅并启动后，`make resume` 自动创建 dockerhub/quay/ghcr 三个 proxy 项目（当前唯一 FAIL 项）
- kubernetes.default 的 legacy Endpoints 对象在 1.36 未自动创建（服务 IP/DNS 不受影响，CoreDNS 走 Service+EndpointSlice）
- kube-controller-manager 偶发 "read version not as new as written" 告警：etcd 3.6 watch 语义 + 大量 watch 场景的已知噪音，etcd 本体健康（raft/applied index 一致、无 alarm）
- 可选扩展：metrics-server、cert-manager、ingress（可复用 lab-gw）、Grafana/Prometheus（密码变量 VAULT_GRAFANA_ADMIN_PASSWORD 已预留）
- OpenClash 若配置 fake-ip TUN 模式，注意与集群 Pod 网段 10.244.0.0/16 的路由排除
