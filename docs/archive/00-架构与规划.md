## 3. 流量与镜像链路

```
K8s Pod 出网 ──► 节点网关 .254 ──► 互联网
K8s 节点拉镜像 ──► http://harbor.yjscloud.local (172.16.222.207, 写入全部节点 /etc/hosts)
                    │ 命中缓存直接返回
                    └ 未命中: Harbor 默认网关=OpenWrt(.210) ──► OpenClash 分流 ──► docker hub / quay / ghcr 回源
OpenWrt 自身 ──► dnsmasq: 本地域 *.yjscloud.local (harbor→.207) + 上游 223.5.5.5
```
